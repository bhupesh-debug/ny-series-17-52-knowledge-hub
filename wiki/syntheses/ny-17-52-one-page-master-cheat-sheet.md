# NY Series 17-52 Accident & Health One-Page High-Yield Cheat Sheet

```
+========================================================================================================+
|                              NY SERIES 17-52 ACCIDENT & HEALTH CRAM SHEET                              |
+========================================================================================================+
| 1. STATUTORY TIMEFRAMES & NUMBERS                                                                      |
| - Grace Periods: 7 days (weekly), 10 days (monthly), 31 days (all others).                              |
| - Reinstatement: 45 days automatic approval; 10-day probationary waiting period for sickness!          |
| - Claims Sequence (20-15-90-60-3):                                                                     |
|     * 20 days: Notice of Claim to insurer.                                                             |
|     * 15 days: Insurer must provide Claim Forms.                                                       |
|     * 90 days: Insured must submit Proof of Loss.                                                      |
|     * 60 days: Mandatory waiting period before filing Legal Action / Lawsuit.                          |
|     * 3 years: Maximum statute of limitations to bring Legal Action.                                   |
| - Free Look (Right to Examine): 10 days standard; 30 DAYS for LTC, MediGap, & Replacement (Reg 60).     |
| - Time Limit on Certain Defenses: 2 YEARS (incontestable after 2 years except for fraudulent non-pay). |
| - Continuing Education (CE): 15 HOURS every 2-year renewal cycle, including 3 HOURS in Ethics.         |
| - Rebating Limit: $25 maximum retail value for promotional items bearing producer/company name.        |
| - Address / Legal Change: 30 DAYS to notify NYDFS Superintendent in writing.                           |
| - DFS Examination: Superintendent examines domestic insurers at least once every 5 YEARS.              |
+--------------------------------------------------------------------------------------------------------+
| 2. SOCIAL INSURANCE COMPARISON: WORKERS' COMP VS. NY DBL                                               |
| - Workers' Comp: On-the-job (occupational); 100% medical covered; 66 2/3% wage benefit.                |
| - NY DBL: Off-the-job (non-occupational); ZERO medical; 50% AWW up to $170/WK MAX; 26 WEEKS MAX.       |
| - NY DBL Waiting Period: 7 DAYS (cash benefits begin on 8th consecutive day of disability).            |
| - SSDI: 5-month waiting period; disability must last >= 12 MONTHS or result in death; strict SGA rule. |
+--------------------------------------------------------------------------------------------------------+
| 3. UNDERWRITING & POLICY DELIVERY ESSENTIALS                                                           |
| - Primary Underwriting Source: THE APPLICATION (not MIB, inspection, or doctor exam).                  |
| - Incomplete Applications: Return to producer! Cannot accept with info added later.                    |
| - MIB (Medical Information Bureau): Impairment CODES ONLY. No credit reports, no moral interviews.     |
| - Inspection Report: Moral character, habits, lifestyle; governed strictly by FCRA (3-day notice).     |
| - Gross Premium Formula: Risk (Mortality/Morbidity) + Expenses (Loading) - Interest Earned.            |
| - Delivery with Prepaid App: Review benefits/exclusions/riders. Free look starts on DELIVERY DATE.     |
| - Delivery Non-Prepaid App: Collect premium + obtain signed Statement of Continued Good Health.       |
| - Change of Occupation in Life: REMAINS IN EFFECT AS ISSUED (unlike Disability which reduces benefit). |
+--------------------------------------------------------------------------------------------------------+
| 4. MEDICARE & SENIOR CARE BLUEPRINT                                                                    |
| - Part A: Hospital, 90-day benefit period, 60 lifetime reserve days, 100 days skilled nursing max.     |
| - Part B: Medical/Doctors, 80/20 coinsurance after annual deductible, optional monthly premium.        |
| - Part C (Medicare Advantage): Private HMO/PPO replacing Parts A & B. CANNOT BE PAIRED WITH MEDIGAP!   |
| - Part D: Standalone Prescription Drug plan.                                                           |
| - MediGap: Standardized Plans A-N. NY has YEAR-ROUND CONTINUOUS OPEN ENROLLMENT & PURE COMMUNITY RATING|
| - LTC Benefit Trigger: 2 of 6 ADLs (BATHED) or severe cognitive impairment. Peril covered = AGING.     |
| - Respite Care: Short-term substitute care to provide temporary relief to unpaid family caregivers.    |
| - NYS Partnership for LTC: Exhaust policy -> Medicaid TOTAL ASSET PROTECTION without spend-down!       |
+--------------------------------------------------------------------------------------------------------+
| 5. TOP 6 EXAM MNEMONICS                                                                                |
| - ACCL: 4 Contract Elements (Agreement, Consideration, Competent parties, Legal purpose).              |
| - BATHED: 6 ADLs (Bathing, Ambulating, Toileting, Hygienic continence, Eating, Dressing).              |
| - 7-10-31: Grace Periods (7 days weekly, 10 days monthly, 31 days all others).                         |
| - 20-15-90-60-3: Claims Sequence (Notice, Forms, Proof, Legal Action wait, Max Lawsuit deadline).       |
| - BSGP (60-70-80-90): ACA Metal Tiers (Bronze 60%, Silver 70%, Gold 80%, Platinum 90%).               |
| - D-C-C-M: Cost-Sharing Order (Deductible -> Copay -> Coinsurance split -> Maximum out-of-pocket).    |
+========================================================================================================+
```
